# 爱 · 花落成蝶

桂花夜景独立作品，三比四画幅。直接打开本目录 `index.html`，无需服务器、联网或安装依赖。原桂花项目没有修改。

## 构图与生长

保留原桂花的 2,017 段枝条和 4,202 朵花，从原有 4,042 片叶子中按前后层与枝组筛选显示 2,828 片，减少约三成。筛选结果固定，保留留下叶片的原位置、大小和生长时间。显示时统一缩放为 60%，根部放在画面左下方（720 × 960 画幅中的 225、770），右上方起初是空的夜色，留给飞来的蝶群与逐渐生成的月亮。树形与枝条保持原样，各层分散疏叶。树干和全部枝条统一使用纯白。叶片以白色和银色分层：受光叶片提亮至纯白，中层为浅银白，背层为银灰；保留五层遮挡和明暗，衬托亮金色桂花。花瓣使用饱和的金黄与浅亮金，暗层保留琥珀金，花心用较深的琥珀色；树上花、花苞和飘落的桂花共用此配色。

- 0～2.7 秒：枝干从根部逐级长成。
- 2.35～3.65 秒：枝条接近长成时开始展叶。
- 约 3.79～5.47 秒：叶子展开后，桂花按原枝组节奏开满。
- 8.5 秒起：一条风线从上方向左下移动。
- 8.75 秒起：树以固定根部轻震一次，同一时刻开始向左落花；震动持续 0.7 秒后恢复静止。112 个固定真实花位在 3.3 秒内交错离枝，下落时间维持原慢版的 48%。
- 花从离枝时树上花位的实际位置出发，离枝后独立向左下偏移，不再跟随树的余震，也不等待落到同一高度才受风。
- 桂花继续随风落向树冠下方，逐朵舒展成蝶。化蝶过程仍沿左下方向，随后再顺风飞 0.6～1.36 秒，各自绕弯赴月。
- 离枝时刻、顺风飞行时长、转向位置和赴月速度固定且错开，画面中会同时出现向下随风飞的蝴蝶与已经向上赴月的蝴蝶。
- 蝴蝶飞行中逐渐放大到起飞时的 1.7 倍，进入未来月面的圆形范围后才渐渐消融；每只蝴蝶消融的进度都累加到月相。
- 夜空最初无月也无月晕，随后随蝶群飞入出现月牙、半月、盈月，直到最后一只蝶融入后成为满月。月相不是单独按秒播放，也不是整张圆盘淡入。
- 24 秒：停在满月与桂花树的画面，可以重播；重播恢复无月夜空。

叶子始终留在树上。落花使用真实桂花位置、大小和四瓣形态的独立副本，树上的花量保持不变；不是叶子化蝶，也不会在起风前抹去树上的花。落花和蝴蝶共用连续轨迹，形态逐渐衔接；中途没有等风的静止阶段。树的位置、枝叶数据和飞行节奏均固定，拖动和重播不会重新随机。

月面改为画布代码绘制：圆弧与椭圆形明暗边界构成月牙，受光区域随蝶群融入向左扩展，最后成为暖白满月；月晕同步增强。旧月亮图片及页面引用已移除。左上角没有文案。

## 播放与文件

按钮支持鼠标、触摸和键盘暂停与重播；进度条支持拖动和方向键微调，显示百分之一秒精度的时间。页面进入后台时暂停；系统要求减少动态效果时，按钮切换初末静态画面。

- `index.html`、`style.css`：独立页面和三比四布局。
- `tree-data.js`：原桂花的完整固定数据，不依赖原目录。
- `scene.js`：夜景、生长、落花化蝶和播放控制。
- `vendor/p5.min.js`：原项目沿用的本地 p5.js 1.9.4。

盛放时复用五层枝叶遮挡关系及花叶缓存；代码月相和夜空不跟随树的缩放；通过每只蝴蝶的实际轨迹计算入月时刻，抵达后的消融和月相共用进度，拖动、暂停、后台恢复都保持一致。

## 检查与人工验收

```sh
node --check tree-data.js
node --check scene.js
node --check tests/scene.test.cjs
node tests/scene.test.cjs
```

逻辑检查验证原枝叶花位及时间不变、母子枝连接、生长先后、左下缩放、真实落花来源、银色叶片、各层约三成疏叶、离枝后立即受风、未化蝶的花向左下偏移、蝶群交错转向、位置与速度连续、飞行中逐渐变大、实际入月消融、无月至满月连续变化、月相复位、49 个进度位置、暂停重播、后台暂停和本地资源。模拟画布检查不等同于浏览器视觉验收。

人工刷新 `index.html` → 播放 → 确认先长枝干、再展叶开花 → 重点看 8.5～10 秒：只有一条风线，树根固定、枝叶轻震一次，同时向左落花，随后树恢复静止 → 看落花化蝶后先顺风飞，再错落转向月亮 → 看蝶群进入右上夜空后，月牙逐渐盈满 → 暂停拖动核对月相 → 重播确认月亮消失。

风的逻辑检查还覆盖单条风线、震动与首次落花同时开始、震动幅度与结束复位、树根固定，以及离枝位置与树上花位的衔接。

本轮未启动服务器、操作浏览器或截图，没有新增网络依赖和临时测试产物。本目录可整体移动。
