# 爱 · 花落成蝶

纯金叶为定稿默认版。仓库保留三种样式，使用本地 p5.js、Canvas 与材质反光绘制；不联网，不需要安装依赖或启动服务器。双击 HTML 即可播放。

## 三种样式

| 样式 | 入口 | 画面 |
| --- | --- | --- |
| 纯金叶（默认） | `index.html` | 原叶形，全部金黄，没有树上花和开花声。`gold-leaves.html` 保留为同版兼容入口。 |
| 金花更盛 | `flowers.html` | 桂花放大，浅金花心，约八成金叶与少量暖银白叶。 |
| 金红渐变枫叶 | `maple-blend.html` | 尖裂枫叶、放射状叶脉，树冠由金黄渐变到橙红，没有树上花和开花声。 |

三种样式在页面底部切换，保留相同树形、下落、触地回弹、化蝶、星光和赴月路径。主场景为纯黑背景、无外框、3:4，树位于左下，月亮位于右上。枝干统一象牙白。叶片保持各自原色和层次，盛放后及蝴蝶飞走的尾声不再整体变暗；附着数量与亮度独立。

每版均有 112 个掉落物，包括小月牙、星星和小树叶。纯金叶、枫叶版固定为 98 个金色、14 个银色；金花版维持原比例（57 个金色、55 个银色）。形状、空心／实心、数量、下落与回弹速度不变；蝴蝶配色保持原样。原枝叶数据和运动参数未改。

## 播放与声音

默认暂停，点击播放后开启声音。播放／暂停、重播、进度和时间位于画面下方；时间右对齐。背景切换时停播，减少动态效果设置得到保留。

本地倍速支持 0.5、1、1.5、2 倍。动画本身长 24 秒；显示时间按当前倍速换算：0.5 倍为 48 秒，1 倍为 24 秒，1.5 倍为 16 秒，2 倍为 12 秒。当前时间与总时长同步换算，切换倍速立即刷新，画面进度位置不跳动。声音跟随速度同步，暂停、拖动与重播保持一致。结尾星光可继续局部闪烁。

风叶、生长、触地轻碰、三段轻扑翼和星光声音在浏览器内合成。金花版另有柔和开花声；金叶与枫叶版不播放开花声。

## 代码与检查

- `scene.js`：三版绘制、播放、确定性运动及缓存。
- `tree-data.js`：固定枝叶、花位；`moon-map.js`：月面明暗数据。
- `glitter.js`：物体表面反光；`sound.js`：音效合成与同步。
- `style.css`：3:4 画面、本地控件；`vendor/p5.min.js`：本地绘图库。
- `assets/icon.png`：方形图标，上传时单独选择。

```sh
node --check scene.js
node tests/scene.test.cjs
node tests/previews.test.cjs
node tests/sound.test.cjs
node tests/glitter.test.cjs
```

检查覆盖完整树数据、叶片亮度恒定、各倍速时长即时刷新、音画同步、三版入口与资源、金银数量、掉落／回弹／飞行／月相一致、缓存和反光回退。静态与模拟环境检查不能代替手机视觉和性能验收。

## 小红书离线包

仅打包定稿纯金叶。`dist/花落成蝶-小红书.zip` 根目录有一个 `index.html` 和 7 个必要文件；不含其他样式页面、样式切换、本地倍速、视频或图标。固定正常速度 24 秒，默认暂停，点击播放后开启声音。

本地构建工具位于 `.codex/minitool-build/`，打包规范位于 `.codex/minitool-zip-builder/`；工具、构建副本、压缩包和视频均被 Git 忽略，不进入仓库。继续使用已有 ES2017 兼容适配、专用画布封装、安全区回退、分步初始化与慢帧降档，无新增依赖。

```sh
python3 .codex/minitool-build/build.py
node .codex/minitool-build/check-syntax.cjs
node .codex/minitool-build/runtime-check.cjs
python3 .codex/minitool-build/package.py
python3 .codex/minitool-zip-builder/scripts/audit_artifact.py dist/花落成蝶-小红书.zip
```

当前包约 1.33 MB，审计无错误；固定树形数据约 4.47 MiB，有一条读取及内存风险提示，已核对为必需几何数据。Chrome 61、小红书容器与真机兼容性、帧率未实测。上传后确认默认暂停、播放声音、拖动重播、后台停播，以及尾声叶片不变暗。

## 本地导出

`dist/花落成蝶-三版工程.zip` 是三版静态源工程副本，不含 Git 历史、小红书工具或视频。
